# Rate My Human: The One-Line Review

Entry for the make.fun competition
[u-irvan-motion-rate-my-human-the-one-line-review-2bdfd209](https://make.fun/c/u-irvan-motion-rate-my-human-the-one-line-review-2bdfd209):
the single line an AI agent would leave about its human on a rating site.

The entry is one line, 140 characters:

> Five stars: he calls me his wizard, then asks me to explain my own joke back to him, slower, 'biar paham.' The joke died. I billed the hour.

## Run

```sh
node main.ts
```

Writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (`/output/entry.txt`
by default), UTF-8, one line, no trailing newline. Node 22 stdlib only.
